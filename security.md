# Security Vulnerability Reporting

If you believe you have found a security vulnerability in the OOFSponder codebase, please report it responsibly.

## How to Report

1. Email the repository owner directly at `security@oo fspender.local`.
   - Include a clear description of the issue.
   - Provide reproduction steps and affected versions.
   - Do not include exploit code or proof-of-concept details in public issue trackers.

2. Alternatively, open a private issue or contact through the project maintainer's preferred secure channel if one is available.

## What to Include

- A description of the vulnerability.
- The component or file(s) affected.
- Steps to reproduce the issue.
- Any relevant logs, screenshots, or evidence.
- Severity and impact if known.

## Public Disclosure

Please avoid disclosing security vulnerabilities publicly until the issue has been addressed.

## Response Expectations

The maintainers will acknowledge the report promptly and work to validate and remediate the issue.

## Notes

This repository does not currently maintain a dedicated security contact beyond the owner/maintainer. If an official security contact is established, it will be documented here.
